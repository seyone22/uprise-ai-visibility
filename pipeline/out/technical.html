3.0 Statistical Estimators

Share of Model Voice (SoMV) & Wilson 95% Confidence Bounds

Share of Model Voice Formulation

We define the empirical Share of Model Voice $\widehat{\text{SoMV}}(E)$ as the unweighted proportion of generative answers naming entity $E$:

$$\widehat{\text{SoMV}}(E) = \left( \frac{1}{N} \sum_{i=1}^{N} \mathbb{I}(E \in \text{Entities}(R_i)) \right) \times 100\%$$

Asymmetric Wilson Score Interval

For binomial proportions across $n=35$ per city and $N=280$ nationally, we compute exact asymmetric Wilson score intervals:

$$w = \frac{\hat{p} + \frac{z^2}{2N} \pm z\sqrt{\frac{\hat{p}(1-\hat{p})}{N} + \frac{z^2}{4N^2}}}{1 + \frac{z^2}{N}}$$

4.0 Prominence & Attention Modeling

Weighted Visibility Index (WVI) Discounted Cumulative Gain

Logarithmic Rank Decay Formula

Entity prominence is weighted by ordinal recommendation position $r_{ik} \in \{1, 2, \dots, K_i\}$ and sentiment stance polarity $S_{ik} \in \{+1.0, +0.5, -0.5\}$:

$$\text{WVI}(E) = \frac{1}{N} \sum_{i=1}^{N} \left( \sum_{k=1}^{K_i} \frac{S_{ik}}{\log_2(r_{ik} + 1)} \cdot \mathbb{I}(E = \text{Entity}_{ik}) \right)$$

Position Discounting Weights

  • Rank 1 ($r=1$): Weight $= 1.000$ (Primary Recommendation)
  • Rank 2 ($r=2$): Weight $= 0.631$ (Strong Secondary Alternative)
  • Rank 3 ($r=3$): Weight $= 0.500$ (Shortlisted Benchmark)
  • Rank 4 ($r=4$): Weight $= 0.431$

10.0 Data Architecture

Database DDL Specification for Monthly 280-Prompt Tracking

Relational Audit Schema (PostgreSQL)

CREATE TABLE geo_evaluations (
    eval_id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    market_id VARCHAR(32) NOT NULL,
    prompt_id VARCHAR(64) NOT NULL,
    engine_id VARCHAR(32) NOT NULL,
    query_text TEXT NOT NULL,
    executed_at TIMESTAMPTZ NOT NULL DEFAULT NOW(),
    raw_response TEXT NOT NULL,
    latency_ms INT
);

CREATE TABLE geo_entity_mentions (
    mention_id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    eval_id UUID REFERENCES geo_evaluations(eval_id),
    entity_name VARCHAR(128) NOT NULL,
    ordinal_rank INT NOT NULL,
    stance VARCHAR(32) CHECK (stance IN ('Strongly Recommended', 'Neutral / Listed', 'Negative')),
    wvi_weight NUMERIC(6,4) GENERATED ALWAYS AS (
        CASE 
            WHEN stance = 'Strongly Recommended' THEN 1.0 / log(2, ordinal_rank + 1)
            WHEN stance = 'Neutral / Listed' THEN 0.5 / log(2, ordinal_rank + 1)
            ELSE -0.5 / log(2, ordinal_rank + 1)
        END
    ) STORED
);

Citation Graph & Leak Tracking Schema

CREATE TABLE geo_citations (
    citation_id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    eval_id UUID REFERENCES geo_evaluations(eval_id),
    source_domain VARCHAR(255) NOT NULL,
    source_url TEXT NOT NULL,
    source_title TEXT,
    is_target_domain BOOLEAN DEFAULT FALSE,
    is_leaked_citation BOOLEAN DEFAULT FALSE
);

CREATE INDEX idx_eval_lookup ON geo_evaluations(market_id, prompt_id, engine_id);
CREATE INDEX idx_entity_rank ON geo_entity_mentions(entity_name, ordinal_rank);

This DDL schema tracks both direct brand mentions and leaked domain citations across the recurring 280-prompt panel.

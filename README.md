Empirical research, mathematical telemetry, and dual-PIN presentation platform for **Uprise Digital Pty Ltd** (`https://uprisedigital.com.au/`).

## System Architecture

- **Sample Universe:** $N = 168$ unprompted commercial queries across 8 Australian capital markets, 7 buying intent prompts, and 3 live authenticated answer engines (Gemini 3.8 Grounded, Claude Sonnet 4.6, Google AI Mode / SERP).
- **Dual-PIN Security:**
  - Client PIN (`2026`): Unlocks Tier 1 Executive Presentation (`/`). Access to `/technical` is blocked (403 Forbidden).
  - Internal PIN (`9418`): Unlocks both Tier 1 Presentation and Tier 2 Technical Dossier (`/technical`).
- **Ned Consultative Standard:** Zero vendor directory checklists on Slide 23; abstracted into 4 high-level authority tiers with zero recipe giveaways.
